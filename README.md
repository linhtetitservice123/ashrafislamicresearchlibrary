# Islamic Research Academy (အစ္စလာမ့် သုတေသန အကယ်ဒမီ)

A modern, scholarly web platform for Islamic research papers, academic treatise repository, paper request board, multilingual typography (Urdu Nastaleeq, Arabic Al Qalam, English Serif, and Myanmar Unicode), and direct Admin WhatsApp & phone consultation.

## 🌟 Features

- **Research Papers Repository**: Browse, search, filter, and read verified Islamic research papers.
- **Multilingual Scholarly Typography**:
  - Urdu (`Jameel Noori Nastaleeq` / `Noto Nastaliq Urdu`)
  - Arabic (`Al Qalam` / `Amiri` / `Scheherazade New`)
  - English (`Cinzel` / `Playfair Display`)
  - Myanmar (`Noto Sans Myanmar` / `Pyidaungsu`)
- **Paper Upload System**: Submit papers with title, author, category, abstract, and file attachments.
- **Paper Request Board**: Community inquiry board where readers request missing religious treatises and books.
- **Admin WhatsApp & Phone Contacts**: 1-click WhatsApp chat links with pre-filled message templates, direct phone calls, and floating contact buttons.
- **Distraction-Free Paper Reader**: Font size controls, parchment/white/sepia/dark themes, and citation generator.

## 🚀 How to Run Locally

```bash
# 1. Install dependencies
npm install

# 2. Run development server
npm run dev

# 3. Build for production (GitHub Pages / Vercel / Netlify)
npm run build
```

## 🌐 Deploy to GitHub Pages

1. Create a repository on GitHub (e.g., `islamic-research-academy`).
2. Push your project files:
   ```bash
   git init
   git add .
   git commit -m "Initial commit of Islamic Research Academy"
   git branch -M main
   git remote add origin https://github.com/<your-username>/<repo-name>.git
   git push -u origin main
   ```
3. Go to **Settings > Pages** on your GitHub repository.
4. Under **Build and deployment**, select **GitHub Actions** or use Vercel / Cloudflare Pages for instant automatic deployment.
